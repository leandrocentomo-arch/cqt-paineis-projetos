# cqt-paineis-projetos

Painéis operacionais da CQT Sistemas da Qualidade, servidos pelo GitHub Pages.

- `painel-sodexo.html`: agenda e notas fiscais compartilhadas com a Sodexo. Traz só agenda, dias, notas emitidas e valor bruto.
- `painel-rubens.html`: painel financeiro interno. Publicado **criptografado** (AES-256-GCM, chave derivada por PBKDF2-SHA256), abre só com senha.
- `new-max-smeta-dashboard.html`: painel SMETA da New Max, também protegido por senha.
- `proteg-dexco.html` e `proteg-dexco-perguntas.html`: material do projeto PROTEG da Dexco.

Os arquivos são gerados a partir do vault de gestão da CQT e publicados por script. Não edite aqui: a próxima publicação sobrescreve.
